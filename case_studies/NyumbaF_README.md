An editorial, high-performance ecommerce platform engineered specifically for contemporary Nairobi urban living. Addresses spatial fit challenges in modern apartments and transparent local delivery zoning.

---

## 🌟 Key Engineering Innovations

1. **"Will It Fit?" Spatial Clearance Calculator:**
   * Interactive TypeScript algorithm evaluating 3D furniture dimensions (Width, Depth, Height, Diagonal) against standard Nairobi building elevators (78cm doors), apartment stairwells (90° turn radius), and interior doorways.
   * Instant visual pass/fail indicator preventing costly return logistics.
2. **Nairobi Zone Delivery Engine:**
   * Flat-rate matrix for Westlands, Kilimani, Lavington, Karen, and Runda, with optional white-glove assembly services (+KES 1,500).
3. **M-Pesa Express STK Push Simulation:**
   * Realistic mobile money checkout simulator with asynchronous payment polling and completion states.
4. **Tactile Editorial Aesthetic:**
   * High-contrast typography, Grevillea & Teak hardwood material breakdown, and responsive mobile-first UI.

## 🚀 Setup & Execution

```bash
# 1. Clone repository
git clone https://github.com/Miltonnare/NyumbaF.git
cd NyumbaF

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Production build
npm run build
```
Accessible locally at `http://localhost:5173`.
